# Changelog

## 0.2.0

- New Start screen with a setup checklist and shortcuts to each area.
- New Quick tasks screen: ready-made jobs (offboarding, inactive users, 2-Step Verification status, mailbox delegation, Drive transfer, Chromebook lookup and more), each explaining what it does and which GAM command it runs.
- Recognizes common Google Workspace and GAM errors and explains how to fix them, with one-click fixes where possible. Works in result panels, pop-up results and the Start checklist.
- Every screen has a "How to use this screen" guide that can be hidden.
- Every action button has a tooltip describing what it does and the GAM command behind it.
- Clearer confirmation window: plain-language summary, the exact commands, and Cancel as the default button.
- Navigation grouped into Manage, Tasks and Advanced.
- Unit tests for the core library.

## 0.1.0

- First release: Users, Groups, Org units, Devices, Drive & Gmail, All commands, Console and Settings.
